Primary action button — full-bleed, uppercase, used at the bottom edge of a screen.

```jsx
<Button variant="alert">Repeat Payment</Button>
<Button variant="ink">Show More</Button>
<Button variant="ghost">Show More</Button>
```

Variants: `alert` (terracotta CTA), `ink` (forest), `ghost` (hairline outline). Never more than one terracotta button per screen.
